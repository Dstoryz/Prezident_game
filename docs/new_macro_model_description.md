# Новая макроэкономическая модель для игры «Президент: Экономика и Власть»

## Краткое описание

Данная модель расширяет классическую макроэкономическую структуру, добавляя:
- Два сектора экономики (промышленность и услуги)
- Валютный курс и внешние шоки
- Закон Оукена (связь безработицы и ВВП)
- Модель инфляции по Филлипсу с ожиданиями
- Taylor-rule для ключевой ставки
- Двухсекторную структуру ВВП
- Динамику государственного долга

Каждый квартал (t) рассчитываются следующие блоки:

---

## 1. Реальный сектор и занятость
### 1.1. Секторальный ВВП
- Два сектора: промышленность (ind) и услуги (srv):
  -  
    Yₜ = Yₜ^ind + Yₜ^srv
    
    Yₜ^ind = Aₜ^ind (Kₜ^ind)^α_ind (Lₜ^ind)^{1-α_ind}
    
    Yₜ^srv = Aₜ^srv (Kₜ^srv)^α_srv (Lₜ^srv)^{1-α_srv}
  
  где Aₜ — технологический уровень, Kₜ, Lₜ — капитал и занятость по секторам, α — капиталоёмкость (примерно 0.3 и 0.4).

### 1.2. Закон Оукена
- Связь между безработицей uₜ и отклонением ВВП от потенциального (output gap):
  
    yₜ^gap = Yₜ / Yₜ^{pot} - 1
    
    uₜ - u_nat = -θ yₜ^gap, θ ≈ 2
  
  где Yₜ^{pot} — потенциальный ВВП, u_nat — натуральная безработица.

---

## 2. Инфляция и денежно-кредитная политика
### 2.1. Динамика инфляции (Филлипс с ожиданиями)
  
    πₜ = β πₜ₋₁ + κ yₜ^gap + γ Δeₜ + εₜ^π
  
  где πₜ — инфляция, yₜ^gap — разрыв выпуска, Δeₜ — изменение логарифма обменного курса, β — коэффициент инфляционных ожиданий, κ — чувствительность к разрыву выпуска, γ — чувствительность к девальвации.

### 2.2. Правило Тейлора для ключевой ставки
  
    iₜ = πₜ + r* + φ_π (πₜ - π*) + φ_y yₜ^gap
  
  где iₜ — ставка, π* — инфляционный таргет, r* — нейтральная ставка, φ_π, φ_y — веса (обычно 0.5–1).

---

## 3. Внешняя торговля и валютный курс
### 3.1. Торговый баланс
  
    NXₜ = Xₜ - Mₜ
    Xₜ = x₀ Yₜ (1 + μₜ^X)
    Mₜ = m₀ Yₜ (1 + μₜ^M)
  
  где Xₜ, Mₜ — экспорт/импорт, μₜ^X, μₜ^M — политические/тарифные марк-апы.

### 3.2. Обменный курс (плавающий)
  
    Δeₜ = ψ (iₜ - iₜ^{rest}) - η TBₜ + εₜ^e
    TBₜ = NXₜ / Yₜ
  
  где iₜ^{rest} — ставка в «мире», ψ, η — чувствительности.

---

## 4. Бюджет и государственный долг
### 4.1. Доходы и расходы
  
    Tₜ = τₜ Yₜ + ρ (Xₜ + Mₜ)
    Gₜ = Σ_i G_{i,ₜ}
  
  где τₜ — налоговая ставка, ρ — ставка пошлин, G_{i,ₜ} — статьи расходов.

### 4.2. Динамика долга
  
    Dₜ = Dₜ₋₁ (1 + rₜ₋₁) + (Gₜ - Tₜ)
  
  где Dₜ — госдолг, rₜ₋₁ — ставка обслуживания.

---

## 5. Демография и социальная сфера
### 5.1. Рост населения
  
    ΔNₜ = Nₜ₋₁ (nₜ^{nat} + nₜ^{mig})
    nₜ^{nat} = b₀ (1 - φ Yₜ / Nₜ₋₁)
    nₜ^{mig} = m₀ (1 + α yₜ^gap - β_u uₜ)
  
  где b₀, m₀ — базовые ставки, φ — демографический переход, α, β_u — чувствительности.

### 5.2. Настроение и трансферты
  
    Moodₜ = min{100, Moodₜ₋₁ + δ (Yₜ + 1) / STₜ}
    STₜ = sₜ Yₜ
  
  где STₜ — соц. трансферты (доля sₜ), δ — мультипликатор настроения.

---

## 6. Кризисы и шоки
- Каждый квартал с вероятностью p может произойти внешний/внутренний шок, задаваемый вектором:
  
    ΔΘ = (Δy, Δπ, Δu, ΔD, ...)
  
  и подмешивается в базовые темпы.
- Примеры:
  - Шок предложения: Δπ = +3%, Δy = −1%
  - Финансовый: Δu = +2%, ΔD = +5%
  - Санкции: ΔX = −10%, Δe = +5%

## Таблица параметров и их ролей
| Блок            | Ключевые параметры         | Что раскрыть игроку         |
|-----------------|---------------------------|-----------------------------|
| Реальный сектор | α, A                      | Y_ind, Y_srv, общий Y       |
| Занятость       | u, u_nat, θ               | Уровень безработицы         |
| Инфляция        | β, κ, γ                   | Текущая и прогноз инфляции  |
| Ставка (Taylor) | φ_π, φ_y, r*, π*          | Ключевая ставка             |
| Торговля и курс | μ_X, μ_M, ψ, η            | Торг. баланс, курс валют    |
| Бюджет и долг   | τ, ρ, r                   | Доходы, расходы, долг       |
| Демография      | b₀, m₀, φ, α              | Рост населения              |
| Соц. сфера      | s, δ                      | Уровень настроения          |
| Шоки            | p, ΔΘ                     | События и их эффект         |

---

## Примечания
- Все параметры и формулы можно адаптировать под балансировку.
- Модель легко расширяется новыми шоками, секторами, социальными эффектами.
