# 🎯 МОНИТОРИНГ АГЕНТОВ - ИНСТРУКЦИЯ

## 🚀 Как следить за работой агентов

### 1. **Полный мониторинг в реальном времени**
```bash
./monitor_agents.sh
```
**Что показывает:**
- ✅ Статус всех агентов (работают/остановлены)
- 🌐 Занятые порты (8000 - Django, 3000 - React)
- 📈 Прогресс разработки (TODO лист, сборка, миграции)
- ⚡ Активные процессы (Django, Node.js, тесты)
- 📝 Последние события каждого агента

**Обновляется каждые 30 секунд**

### 2. **Быстрый просмотр логов**
```bash
# Все агенты (последние 3 строки каждого)
./quick_logs.sh

# Конкретный агент (последние 10 строк)
./quick_logs.sh architect
./quick_logs.sh backend
./quick_logs.sh frontend
./quick_logs.sh testing
./quick_logs.sh devops
./quick_logs.sh analyst
```

### 3. **Прямой просмотр логов**
```bash
# Архитектор (координатор)
tail -f agents/logs/architect_*.log

# Backend разработка
tail -f agents/logs/backend_*.log

# Frontend разработка
tail -f agents/logs/frontend_*.log

# Тестирование
tail -f agents/logs/testing_*.log

# DevOps
tail -f agents/logs/devops_*.log

# Аналитик
tail -f agents/logs/analyst_*.log
```

### 4. **Проверка статуса процессов**
```bash
# Все агенты
ps aux | grep -E "(architect|backend|frontend|testing|devops|analyst)" | grep -v grep

# Конкретный агент
ps aux | grep architect_agent.sh
```

### 5. **Проверка портов**
```bash
# Django API (порт 8000)
lsof -i :8000

# React Dev Server (порт 3000)
lsof -i :3000
```

## 📊 Что делают агенты

### 🤖 **Architect** (координатор)
- Мониторит работу всех агентов
- Координирует задачи между агентами
- Проверяет API и frontend
- Создает отчеты о прогрессе

### 🐍 **Backend** (Django разработка)
- Проверяет Django API
- Тестирует сервисы (economic_model, event_generator)
- Проверяет сериализаторы и views
- Мониторит производительность

### 🟢 **Frontend** (React разработка)
- Собирает React приложение
- Проверяет компоненты
- Тестирует интеграцию с API
- Мониторит использование памяти

### 🧪 **Testing** (тестирование)
- Запускает автоматические тесты
- Проверяет API endpoints
- Тестирует регистрацию/авторизацию
- Проверяет производительность

### ⚙️ **DevOps** (инфраструктура)
- Мониторит систему
- Проверяет зависимости
- Управляет развертыванием
- Обеспечивает стабильность

### 📈 **Analyst** (аналитика)
- Анализирует метрики
- Создает отчеты
- Мониторит производительность
- Предоставляет рекомендации

## 🎯 Рекомендуемый режим мониторинга

1. **Запустите полный мониторинг:**
   ```bash
   ./monitor_agents.sh
   ```

2. **В отдельном терминале следите за конкретным агентом:**
   ```bash
   tail -f agents/logs/architect_*.log
   ```

3. **Для быстрых проверок:**
   ```bash
   ./quick_logs.sh
   ```

## 🚨 Если что-то пошло не так

### Агент остановился
```bash
# Перезапуск всех агентов
./agents/start_agents.sh

# Или конкретного агента
./agents/architect_agent.sh &
```

### Зависшие процессы
```bash
# Остановка всех процессов
killall python node curl

# Проверка и остановка зависших процессов
ps aux | grep -E "(python|node)" | grep -v grep
kill -9 [PID]
```

### Проблемы с портами
```bash
# Освобождение портов
fuser -k 8000/tcp
fuser -k 3000/tcp
```
