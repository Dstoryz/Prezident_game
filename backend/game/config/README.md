# Конфигурация экономической модели

## Обзор

Файл `economic_config.py` содержит все внешние параметры экономической модели "Президент: Экономика и Власть". Это позволяет легко настраивать модель без изменения основного кода.

## Основные разделы конфигурации

### 1. Основные экономические параметры
- **INITIAL_GDP** - начальный ВВП (млрд долларов)
- **INITIAL_POPULATION** - начальная численность населения (млн человек)
- **INITIAL_INFLATION** - начальная инфляция (% в год)
- **INITIAL_UNEMPLOYMENT** - начальная безработица (%)
- **INITIAL_INTEREST_RATE** - начальная процентная ставка (%)

### 2. Секторальные параметры (упрощенные)
- **INDUSTRY_SHARE** - доля промышленности в экономике (35%)
- **SERVICES_SHARE** - доля услуг в экономике (65%)
- **INDUSTRY_CAPITAL_ELASTICITY** - эластичность производства по капиталу в промышленности
- **SERVICES_CAPITAL_ELASTICITY** - эластичность производства по капиталу в услугах

### 3. Бюджетные параметры
- **CORPORATE_TAX_RATE** - ставка корпоративного налога (20%)
- **INCOME_TAX_RATE** - ставка подоходного налога (15%)
- **VAT_RATE** - ставка НДС (18%)
- **SOCIAL_SPENDING_RATIO** - доля социальных расходов от ВВП (25%)

### 4. Монетарные параметры
- **MONEY_MULTIPLIER** - денежный мультипликатор (3.0)
- **RESERVE_RATIO** - норма резервирования (10%)
- **INFLATION_TARGET** - целевая инфляция (2.0%)

### 5. Политические параметры
- **PRESIDENT_RATING_BASE** - базовый рейтинг президента (50.0)
- **RATING_GROWTH_WEIGHT** - вес роста ВВП в рейтинге (0.4)
- **RATING_INFLATION_WEIGHT** - вес инфляции в рейтинге (0.3)
- **RATING_UNEMPLOYMENT_WEIGHT** - вес безработицы в рейтинге (0.3)

### 6. Кризисные параметры
- **CRISIS_PROBABILITY_BASE** - базовая вероятность кризиса (5% в год)
- **CRISIS_GDP_IMPACT** - влияние кризиса на ВВП (-5%)
- **CRISIS_INFLATION_IMPACT** - влияние кризиса на инфляцию (+3%)
- **CRISIS_RATING_IMPACT** - влияние кризиса на рейтинг (-10 пунктов)

## Как изменить параметры

### Для изменения сложности игры:
```python
# Легкий уровень
INITIAL_GDP = 1500.0  # Больше начальный ВВП
CRISIS_PROBABILITY_BASE = 0.02  # Меньше кризисов

# Сложный уровень  
INITIAL_GDP = 500.0  # Меньше начальный ВВП
CRISIS_PROBABILITY_BASE = 0.10  # Больше кризисов
```

### Для изменения экономической структуры:
```python
# Индустриальная экономика
INDUSTRY_SHARE = 0.60  # 60% промышленность
SERVICES_SHARE = 0.40  # 40% услуги

# Постиндустриальная экономика
INDUSTRY_SHARE = 0.20  # 20% промышленность  
SERVICES_SHARE = 0.80  # 80% услуги
```

### Для изменения политических приоритетов:
```python
# Консервативная политика
RATING_INFLATION_WEIGHT = 0.5  # Больше внимания инфляции
RATING_GROWTH_WEIGHT = 0.3     # Меньше внимания росту

# Прогрессивная политика
RATING_GROWTH_WEIGHT = 0.6     # Больше внимания росту
RATING_INFLATION_WEIGHT = 0.2  # Меньше внимания инфляции
```

## Преимущества конфигурационного подхода

1. **Простота настройки** - все параметры в одном месте
2. **Гибкость** - легко создавать разные сценарии
3. **Читаемость** - понятные названия параметров с комментариями
4. **Безопасность** - изменения не затрагивают основной код
5. **Масштабируемость** - легко добавлять новые параметры

## Рекомендации по настройке

- Изменяйте параметры постепенно, тестируя каждое изменение
- Следите за балансом между реалистичностью и игровым процессом
- Документируйте изменения для других разработчиков
- Создавайте профили настроек для разных уровней сложности
