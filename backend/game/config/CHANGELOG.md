# Журнал изменений конфигурации

## Версия 1.0.0 - Вынос параметров в конфигурационный файл

### Добавлено
- **Конфигурационный файл** `economic_config.py` с всеми внешними параметрами модели
- **Профили сложности** в `difficulty_profiles.py` для разных уровней игры
- **Документация** по конфигурации в `README.md`
- **Тестовый скрипт** `test_config.py` для проверки конфигурации

### Изменено
- **Упрощены секторальные параметры** - убраны избыточные детали, оставлены только ключевые
- **Модель использует конфигурацию** - все параметры теперь берутся из конфига
- **Улучшена читаемость** - параметры сгруппированы по категориям с комментариями

### Структура конфигурации

#### Основные экономические параметры
- `INITIAL_GDP` - начальный ВВП (1000 млрд $)
- `INITIAL_POPULATION` - начальная численность населения (150 млн чел.)
- `INITIAL_INFLATION` - начальная инфляция (2.5%)
- `INITIAL_UNEMPLOYMENT` - начальная безработица (5.0%)
- `INITIAL_INTEREST_RATE` - начальная процентная ставка (4.0%)

#### Секторальные параметры (упрощенные)
- `INDUSTRY_SHARE` - доля промышленности (35%)
- `SERVICES_SHARE` - доля услуг (65%)
- `INDUSTRY_CAPITAL_ELASTICITY` - эластичность по капиталу в промышленности (0.3)
- `SERVICES_CAPITAL_ELASTICITY` - эластичность по капиталу в услугах (0.25)

#### Бюджетные параметры
- `CORPORATE_TAX_RATE` - ставка корпоративного налога (20%)
- `INCOME_TAX_RATE` - ставка подоходного налога (15%)
- `VAT_RATE` - ставка НДС (18%)
- `SOCIAL_SPENDING_RATIO` - доля социальных расходов (25%)

#### Политические параметры
- `PRESIDENT_RATING_BASE` - базовый рейтинг президента (50.0)
- `RATING_GROWTH_WEIGHT` - вес роста ВВП в рейтинге (0.4)
- `RATING_INFLATION_WEIGHT` - вес инфляции в рейтинге (0.3)
- `RATING_UNEMPLOYMENT_WEIGHT` - вес безработицы в рейтинге (0.3)

#### Кризисные параметры
- `CRISIS_PROBABILITY_BASE` - базовая вероятность кризиса (5% в год)
- `CRISIS_GDP_IMPACT` - влияние кризиса на ВВП (-5%)
- `CRISIS_INFLATION_IMPACT` - влияние кризиса на инфляцию (+3%)
- `CRISIS_RATING_IMPACT` - влияние кризиса на рейтинг (-10 пунктов)

### Преимущества новой конфигурации

1. **Простота настройки** - все параметры в одном месте
2. **Гибкость** - легко создавать разные сценарии
3. **Читаемость** - понятные названия параметров с комментариями
4. **Безопасность** - изменения не затрагивают основной код
5. **Масштабируемость** - легко добавлять новые параметры
6. **Тестируемость** - автоматическая проверка корректности конфигурации

### Как использовать

#### Изменение параметров
```python
# В файле economic_config.py
INITIAL_GDP = 1200.0  # Изменить начальный ВВП
CRISIS_PROBABILITY_BASE = 0.03  # Уменьшить вероятность кризисов
```

#### Применение профиля сложности
```python
from game.config.difficulty_profiles import apply_difficulty_profile

# Применить легкий уровень
easy_config = apply_difficulty_profile('easy')

# Применить сложный уровень
hard_config = apply_difficulty_profile('hard')
```

#### Тестирование конфигурации
```bash
python test_config.py
```
