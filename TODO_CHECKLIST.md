#### Процентная ставка (interest_rate)
- [ ] **Высокая ставка (15-20%)** → снижение инфляции

- [ ] **Высокая ставка (15-20%)** → снижение инвестиций
- [ ] **Низкая ставка (0-5%)** → рост инфляции
- [ ] **Низкая ставка (0-5%)** → снижение безработицы
- [ ] **Низкая ставка (0-5%)** → рост инвестиций
- [ ] **Влияние на курс валюты** - высокая ставка укрепляет валюту
- [ ] **Влияние на внешнюю торговлю** - высокая ставка снижает экспорт

#### Налоговая нагрузка (tax_rate)
- [ ] **Высокие налоги (30-50%)** → снижение инвестиций

- [ ] **Низкие налоги (0-15%)** → снижение доходов бюджета
- [ ] **Влияние на ВВП** - высокие налоги тормозят рост

## 👥 ПРОВЕРКА ДЕМОГРАФИЧЕСКОЙ МОДЕЛИ И АДЕКВАТНОСТИ РЕАЛЬНЫМ ЗАКОНОМЕРНОСТЯМ

### Базовые демографические параметры

#### Начальные значения
- [ ] **Начальная численность населения** = 150 млн человек (реалистично для средней страны)
- [ ] **Базовый естественный прирост** = 0.8% в год (соответствует современным развитым странам)
- [ ] **Базовая миграция** = 0.5% в год (реалистично для открытых экономик)
- [ ] **Базовая продолжительность жизни** = 70 лет (средний уровень)

### Естественный прирост населения

#### Влияние качества здравоохранения
- [ ] **Высокое качество здравоохранения (70-100)** → рост естественного прироста
- [ ] **Низкое качество здравоохранения (0-30)** → снижение естественного прироста
- [ ] **Среднее качество здравоохранения (40-60)** → стабильный прирост
- [ ] **Формула работает корректно**: `natural_growth = base_growth * (1 + (healthcare_quality - 50) * 0.01)`

#### Демографический переход
- [ ] **Высокий ВВП на душу населения** → снижение естественного прироста (демографический переход)
- [ ] **Низкий ВВП на душу населения** → высокий естественный прирост
- [ ] **Формула демографического перехода**: `natural_growth = base_growth * (1 - demographic_transition * gdp_per_capita)`

### Миграционный прирост

#### Влияние экономических условий
- [ ] **Высокий рост ВВП** → приток мигрантов (положительная миграция)
- [ ] **Высокая безработица** → отток населения (отрицательная миграция)
- [ ] **Низкий рост ВВП** → отток населения
- [ ] **Низкая безработица** → приток мигрантов
- [ ] **Формула миграции**: `migration = base_migration * (1 + gdp_growth * 0.1 - unemployment * 0.05)`

#### Реалистичность миграционных потоков
- [ ] **Миграция не превышает 2-3%** от населения в год (реалистично)
- [ ] **Миграция может быть отрицательной** при плохих экономических условиях
- [ ] **Миграция зависит от ВВП на душу населения** (а не от абсолютного ВВП)

### Продолжительность жизни

#### Влияние здравоохранения
- [ ] **Высокое качество здравоохранения** → рост продолжительности жизни
- [ ] **Низкое качество здравоохранения** → снижение продолжительности жизни
- [ ] **Формула**: `life_expectancy = 70 + (healthcare_quality - 50) * 0.2`
- [ ] **Диапазон продолжительности жизни** 60-80 лет (реалистично)

### Проверка реалистичности модели

#### Темпы роста населения
- [ ] **Общий рост населения** не превышает 3-4% в год (реалистично)
- [ ] **Отрицательный рост** возможен при кризисах
- [ ] **Стабильный рост** при хороших экономических условиях

##### Сценарий 1: Развитая экономика
