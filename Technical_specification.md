📝 Техническое задание

Название проекта: Президент: Экономика и Власть
Тип продукта: Браузерная однопользовательская экономико-политическая стратегия
Цель игры: Управляя страной в роли президента, игрок должен как можно дольше оставаться у власти, принимая решения в сфере макроэкономики и реагируя на внутренние и внешние события.
1. Целевая аудитория

    Студенты экономических вузов

    Пользователи, интересующиеся экономикой и политикой

2. Игровая механика
2.1. Управляемые параметры (выставляются игроком):

    Процентная ставка

    Налоговая нагрузка

    Государственные расходы

    Таможенные пошлины (опционально)

2.2. Рассчитываемые показатели:

    ВВП (темп роста)

    Инфляция

    Уровень безработицы

    Объём инвестиций

    Рейтинг поддержки президента

2.3. Случайные события (генерируются системой):

    Природные катастрофы

    Экономические кризисы

    Санкции/торговые ограничения

    Международные конфликты

    Рост или падение цен на сырьё

    Социальные протесты

2.4. Игровой цикл:

    Один ход = один квартал

    Игрок выставляет параметры и запускает следующий ход

    Система рассчитывает экономику, генерирует события, обновляет показатели

    Каждые 4 года (16 ходов) проходят выборы:

        Если рейтинг поддержки < 50% — игра завершается

        Если ≥ 50% — игрок остаётся на следующий срок

3. Интерфейс
3.1. Главный экран:

    Панель управления параметрами (слайдеры/вводы)

    Панель отображения текущих показателей

    Блок текущих событий

    График динамики показателей (линии, столбцы)

    Кнопка «Следующий ход»

3.2. Экран выборов:

    Отображение рейтинга и исход выборов

3.3. Дополнительные элементы:

    Таймер до следующих выборов

    Подсказки при наведении (объяснение параметров)

4. Техническая реализация
4.1. Frontend

    React (с использованием функциональных компонентов)

    Стилизация: Tailwind CSS или Material UI

    Графики: Recharts или Chart.js

    Состояние: Context API или Redux (по необходимости)

    Взаимодействие с API: через Axios или fetch

    Частичное сохранение игры в localStorage

4.2. Backend

    Django + Django REST Framework

    Сущности:

        Пользователь (опционально)

        Игровая сессия

        Параметры управления

        Показатели экономики

        События

    Эндпоинты:

        POST /api/game/start — начать игру

        POST /api/game/next-turn — обработать ход, вернуть новые данные

        GET /api/game/state — получить текущее состояние игры

        (опционально) POST /api/game/save, GET /api/game/load

5. Экономическая логика
5.1. Формула рейтинга (примерная):

rating = 50 + gdp_growth * 2 - inflation * 2 - unemployment * 1.5 + public_mood * 1.5

5.2. Влияние параметров:

    Высокая ставка → снижение инфляции, рост безработицы

    Рост налогов → падение инвестиций, рост недовольства

    Увеличение расходов → рост ВВП, но возможная инфляция

    Валютные шоки → изменение экспорта/импорта

6. Хранение данных

    Без авторизации: всё хранится в localStorage

    С авторизацией: хранение сессии в базе данных (PostgreSQL/SQLite)

7. Возможности расширения

    Сценарии: «кризис», «нефтяной шок», «глобальная рецессия»

    Множественные страны и конкуренция

    Обучающий режим с подсказками

    Режим мультиплеера или рейтинговой игры

8. Требования к качеству

    Простота и наглядность интерфейса

    Быстрая реакция UI на действия игрока

    Обработка некорректных значений

    Кроссбраузерность (Chrome, Firefox, Safari)

    Адаптация под планшеты
