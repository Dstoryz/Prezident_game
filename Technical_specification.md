Название проекта: Президент: Экономика и Власть
Тип продукта: Браузерная однопользовательская экономико-политическая стратегия
Цель игры: Управляя страной в роли президента, игрок должен как можно дольше оставаться у власти, принимая решения в сфере макроэкономики и реагируя на внутренние и внешние события.

## 1. Целевая аудитория

- Студенты экономических вузов
- Пользователи, интересующиеся экономикой и политикой
- Преподаватели экономики для образовательных целей

## 2. Игровая механика

### 2.1. Управляемые параметры (выставляются игроком):

- **Процентная ставка** (0-20%) - влияет на кредитование и инвестиции
- **Налоговая нагрузка** (0-50%) - влияет на бюджет и экономическую активность
- **Государственные расходы** (10-50% от ВВП) - влияет на экономический рост
- **Таможенные пошлины** (0-30%) - влияет на внешнюю торговлю
- **Бюджетные приоритеты** (распределение бюджета):
  - Образование и наука (0-40%)
  - Здравоохранение (0-40%)
  - Оборона (0-40%)
  - Инфраструктура (0-40%)
  - Социальная защита (0-40%)

### 2.2. Рассчитываемые показатели:

#### Основные экономические показатели:
- **ВВП** (абсолютное значение и темп роста)
- **ВВП на душу населения**
- **Инфляция** (%)
- **Уровень безработицы** (%)
- **Объём инвестиций** (% от ВВП)
- **Бюджет** (доходы, расходы, дефицит/профицит)
- **Накопления** (государственные резервы)

#### Демографические показатели:
- **Численность населения** (млн человек)
- **Естественный прирост населения** (%)
- **Миграционный прирост** (%)
- **Средняя продолжительность жизни** (лет)

#### Производственные показатели (модель Солоу):
- **Капиталовооруженность** (капитал на одного работника)
- **Производительность труда**
- **Технологический прогресс** (фактор A в модели Солоу)
- **Норма сбережений** (%)
- **Норма амортизации** (%)

#### Социальные показатели:
- **Рейтинг поддержки президента** (%)
- **Настроение населения** (%)
- **Уровень образования** (среднее количество лет обучения)
- **Качество здравоохранения** (индекс)

#### Внешнеэкономические показатели:
- **Объём экспорта** (% от ВВП)
- **Объём импорта** (% от ВВП)
- **Торговый баланс** (% от ВВП)
- **Курс валюты** (индекс)

### 2.3. Случайные события (генерируются системой):

- **Природные катастрофы** (землетрясения, наводнения, засухи)
- **Экономические кризисы** (банковские кризисы, дефолты)
- **Санкции/торговые ограничения** (внешнеэкономические шоки)
- **Международные конфликты** (войны, дипломатические кризисы)
- **Рост или падение цен на сырьё** (нефть, газ, металлы)
- **Социальные протесты** (забастовки, митинги)
- **Технологические прорывы** (инновации, научные открытия)
- **Демографические изменения** (бэби-бум, старение населения)

### 2.4. Игровой цикл:

- Один ход = один квартал
- Игрок выставляет параметры и запускает следующий ход
- Система рассчитывает экономику по модели Солоу, генерирует события, обновляет показатели
- Каждые 4 года (16 ходов) проходят выборы:
  - Если рейтинг поддержки < 50% — игра завершается
  - Если ≥ 50% — игрок остаётся на следующий срок

## 5. Экономическая логика

### 5.1. Модель Солоу

```python
# Производственная функция: Y = A * K^α * L^(1-α)
# где:
# Y - ВВП
# A - технологический прогресс
# K - капитал
# L - труд
# α - доля капитала в производстве (обычно 0.3-0.4)

# Динамика капитала: dK/dt = s*Y - δ*K
# где:
# s - норма сбережений
# δ - норма амортизации
```

### 5.2. Бюджетная логика

```python
# Доходы бюджета
tax_revenue = gdp * tax_rate / 100
customs_revenue = (exports + imports) * customs_duty / 100
total_revenue = tax_revenue + customs_revenue

# Расходы бюджета
education_spending = total_revenue * education_priority / 100
healthcare_spending = total_revenue * healthcare_priority / 100
defense_spending = total_revenue * defense_priority / 100
infrastructure_spending = total_revenue * infrastructure_priority / 100
social_spending = total_revenue * social_priority / 100

# Бюджетный баланс
budget_balance = total_revenue - total_spending
accumulated_reserves += budget_balance
```

### 5.3. Демографическая логика

```python
# Естественный прирост
natural_growth = base_natural_growth * (1 + healthcare_quality * 0.01)

# Миграционный прирост
migration_growth = base_migration * (1 + gdp_growth * 0.1 - unemployment * 0.05)

# Изменение населения
population_change = population * (natural_growth + migration_growth) / 100
new_population = population + population_change

# Продолжительность жизни
life_expectancy = base_life_expectancy + healthcare_quality * 0.1
```

### 5.4. Формула рейтинга президента

```python
rating = 50 + gdp_growth * 2 - inflation * 2 - unemployment * 1.5 + 
         public_mood * 0.3 + education_quality * 0.2 + healthcare_quality * 0.2 +
         budget_balance_percent * 0.5
```

### 5.5. Влияние параметров управления

#### Процентная ставка:
- Высокая ставка → снижение инфляции, рост безработицы, снижение инвестиций
- Низкая ставка → рост инфляции, снижение безработицы, рост инвестиций

#### Налоговая нагрузка:
- Высокие налоги → падение инвестиций, рост недовольства, снижение экономической активности
- Низкие налоги → рост инвестиций, снижение недовольства, рост экономической активности

#### Государственные расходы:
- Увеличение расходов → рост ВВП, возможная инфляция, улучшение социальных показателей
- Снижение расходов → снижение ВВП, снижение инфляции, ухудшение социальных показателей

#### Бюджетные приоритеты:
- Образование → рост технологического прогресса, повышение производительности
- Здравоохранение → рост продолжительности жизни, снижение смертности
- Оборона → рост безопасности, возможное влияние на внешнюю политику
- Инфраструктура → рост производительности, снижение издержек
- Социальная защита → улучшение настроения населения, снижение социальной напряженности
