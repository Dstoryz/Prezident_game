# 📋 План внедрения новой макроэкономической модели

## Цель
Внедрить новую расширенную макроэкономическую модель из `docs/new_macro_model_description.md` в существующий проект, не нарушая текущую функциональность.

## Этапы внедрения

### Этап 1: Подготовка и анализ (Архитектор-агент)
**Задачи:**
- [ ] Проанализировать новую модель и сравнить с текущей
- [ ] Создать план миграции данных
- [ ] Определить точки интеграции
- [ ] Создать схему API для новой модели

### Этап 2: Бэкенд - Создание новой модели (Бэкенд-агент)
**Задачи:**
- [ ] Создать `enhanced_economic_model.py` с новой логикой
- [ ] Реализовать двухсекторную модель (промышленность + услуги)
- [ ] Добавить закон Оукена и кривую Филлипса
- [ ] Реализовать правило Тейлора для ставки
- [ ] Добавить валютный курс и внешнюю торговлю
- [ ] Создать систему кризисов и шоков
- [ ] Добавить новые API эндпоинты для тестирования

### Этап 3: Бэкенд - Интеграция (Бэкенд-агент)
**Задачи:**
- [ ] Создать переключатель между старой и новой моделью
- [ ] Обновить сериализаторы для новых полей
- [ ] Добавить миграции БД для новых полей
- [ ] Создать тестовые данные для новой модели

### Этап 4: Фронтенд - Новые компоненты (Фронтенд-агент)
**Задачи:**
- [ ] Создать компонент для отображения двух секторов
- [ ] Добавить графики валютного курса
- [ ] Создать панель кризисов и событий
- [ ] Обновить дашборд для новых показателей
- [ ] Добавить переключатель между моделями

### Этап 5: Тестирование (Агент-тестировщик)
**Задачи:**
- [ ] Протестировать новую модель отдельно
- [ ] Проверить переключение между моделями
- [ ] Тестировать API эндпоинты
- [ ] Проверить корректность расчетов
- [ ] Тестировать UI компоненты

### Этап 6: Документация и финализация (Архитектор-агент)
**Задачи:**
- [ ] Обновить документацию API
- [ ] Создать руководство по новой модели
- [ ] Подготовить релизные заметки
- [ ] Провести финальное тестирование

## Команды для агентов

### Архитектор-агент:
```
1. Проанализируй новую модель из docs/new_macro_model_description.md
2. Создай детальный план внедрения с учетом текущей архитектуры
3. Определи приоритеты и зависимости между задачами
4. Координируй работу всех агентов
```

### Бэкенд-агент:
```
1. Создай enhanced_economic_model.py с новой логикой
2. Реализуй двухсекторную модель ВВП
3. Добавь закон Оукена и кривую Филлипса
4. Реализуй правило Тейлора
5. Создай API для тестирования новой модели
6. Добавь переключатель между моделями
```

### Фронтенд-агент:
```
1. Создай компонент SectorDashboard для отображения двух секторов
2. Добавь график валютного курса
3. Создай панель кризисов и событий
4. Обнови GameDashboard для новых показателей
5. Добавь переключатель моделей в интерфейс
```

### Агент-тестировщик:
```
1. Протестируй новую модель отдельно
2. Проверь переключение между моделями
3. Тестируй все новые API эндпоинты
4. Проверь корректность расчетов
5. Тестируй UI компоненты
```

## Критерии успеха
- [ ] Новая модель работает параллельно со старой
- [ ] Можно переключаться между моделями
- [ ] Все новые показатели корректно рассчитываются
- [ ] UI отображает новые данные
- [ ] Нет регрессий в существующей функциональности

## Риски и митигация
- **Риск:** Сложность новой модели может замедлить разработку
  - **Митигация:** Начать с упрощенной версии, постепенно добавляя сложность
- **Риск:** Новая модель может быть нестабильной
  - **Митигация:** Тщательное тестирование и возможность отката к старой модели
- **Риск:** UI может стать перегруженным
  - **Митигация:** Поэтапное добавление компонентов с возможностью скрытия
