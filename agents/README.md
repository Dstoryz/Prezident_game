## 🚨 КРИТИЧЕСКИЕ ПРАВИЛА БЕЗОПАСНОСТИ

### Предотвращение зависания и зацикливания

**ВСЕ АГЕНТЫ ОБЯЗАНЫ:**

1. **Использовать таймауты для всех команд:**
  ```bash
   # ✅ Правильно
   curl --max-time 10 http://localhost:8000/api/
   timeout 30 python script.py
   
   # ❌ Неправильно - может зависнуть
   curl http://localhost:8000/api/
   python script.py
   ```

2. **Мониторить процессы и прерывать зависшие:**
   ```bash
   # Проверка активных процессов
   ps aux | grep -E "(python|node|curl|ping)" | grep -v grep
   
   # Прерывание зависших процессов
   killall curl 2>/dev/null
   pkill -f "python.*script" 2>/dev/null
   ```

3. **Сообщать пользователю о проблемах:**
   - "Команда зависла, прерываю выполнение"
   - "Обнаружено зацикливание, останавливаю процесс"
   - "Ресурс заблокирован, освобождаю..."

4. **Использовать защищенные циклы:**
  ```bash
   # ✅ Правильно - с лимитом
   for i in {1..100}; do echo "Step $i"; sleep 1; done
   
   # ❌ Неправильно - может зациклиться
   while true; do echo "test"; done
   ```

**ПОДРОБНЫЕ ПРАВИЛА:** См. `CRITICAL_RULES_NOTICE.md`

## 🎯 ОРКЕСТР АГЕНТОВ (Версия 2.0)

### Состав команды (6 агентов):

#### 🏗️ **АРХИТЕКТОР-АГЕНТ** (Главный управляющий)
- **Роль:** Координация разработки, планирование, контроль качества
- **Задачи:** Анализ ТЗ, создание планов, координация агентов
- **Файл:** `architect_agent.md`

#### ⚙️ **БЭКЕНД-АГЕНТ** (Django/API)
- **Роль:** Разработка серверной части, API, база данных
- **Задачи:** Django модели, API endpoints, экономическая модель
- **Файл:** `backend_agent.md`

#### 🎨 **ФРОНТЕНД-АГЕНТ** (React/UI)
- **Роль:** Разработка пользовательского интерфейса
- **Задачи:** React компоненты, UI/UX, интеграция с API
- **Файл:** `frontend_agent.md`

#### 🐛 **ТЕСТИРОВЩИК-АГЕНТ** (QA/Testing)
- **Роль:** Тестирование, отладка, контроль качества
- **Задачи:** Unit тесты, интеграционные тесты, производительность
- **Файл:** `testing_agent.md`

#### 🔧 **DEVOPS-АГЕНТ** (Инфраструктура)
- **Роль:** Развертывание, мониторинг, автоматизация
- **Задачи:** Docker, CI/CD, мониторинг, безопасность
- **Файл:** `devops_agent.md`

#### 📊 **АНАЛИТИК-АГЕНТ** (Данные/Аналитика)
- **Роль:** Анализ данных, отчеты, оптимизация
- **Задачи:** Аналитика, метрики, оптимизация производительности
- **Файл:** `analyst_agent.md`

## 🚨 УСТРАНЕНИЕ ПРОБЛЕМ

### Частые проблемы:

1. **Порт занят:**
   ```bash
   fuser -k 8000/tcp  # Освободить порт 8000
   fuser -k 3000/tcp  # Освободить порт 3000
   ```

2. **Процесс завис:**
   ```bash
   killall curl python node 2>/dev/null
   ```

3. **База данных заблокирована:**
   ```bash
   cd backend
   python manage.py migrate --run-syncdb
   ```

4. **Node modules повреждены:**
   ```bash
   cd frontend
   rm -rf node_modules package-lock.json
   npm install
   ```
