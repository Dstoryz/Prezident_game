# 🤖 Система агентов для проекта "Президент: Экономика и Власть"

## Обзор
Система состоит из 4 специализированных агентов, каждый из которых отвечает за свою область разработки.

## Агенты

### 🏗️ Архитектор-агент (Главный управляющий)
**Файл:** `architect_agent.md`
- Координирует работу всех агентов
- Принимает ключевые решения по архитектуре
- Контролирует качество и соответствие ТЗ
- Создает план разработки

### 🎨 Фронтенд-агент
**Файл:** `frontend_agent.md`
- Разрабатывает React-компоненты
- Создает пользовательский интерфейс
- Интегрирует с API
- Работает с графиками и визуализацией

### ⚙️ Бэкенд-агент
**Файл:** `backend_agent.md`
- Разрабатывает Django-приложение
- Создает REST API
- Реализует экономическую логику
- Работает с базой данных

### 🐛 Агент-тестировщик
**Файл:** `testing_agent.md`
- Выявляет ошибки и баги
- Тестирует функциональность
- Проверяет производительность
- Анализирует безопасность

## Как использовать

### 1. Запуск агентов
При обращении к агенту, используйте его роль:
```
Архитектор-агент, проанализируй ТЗ и создай план разработки
Фронтенд-агент, создай компонент GameDashboard
Бэкенд-агент, реализуй API для начала игры
Агент-тестировщик, проверь экономическую логику
```

### 2. Иерархия команд
- **Архитектор-агент** имеет право давать команды всем остальным агентам
- Остальные агенты выполняют задачи в своих областях
- Агент-тестировщик может проверять работу всех агентов

### 3. Процесс разработки
1. **Архитектор-агент** анализирует задачу и создает план
2. **Бэкенд-агент** и **Фронтенд-агент** работают параллельно
3. **Агент-тестировщик** проверяет качество на каждом этапе
4. **Архитектор-агент** координирует интеграцию

## Статус проекта
**Фаза:** Настройка агентов
**Следующий шаг:** Архитектор-агент должен проанализировать ТЗ и создать план разработки

## Команды для запуска
```
# Начать работу
Архитектор-агент, проанализируй ТЗ и создай план разработки

# Создать структуру проекта
Архитектор-агент, создай структуру папок для проекта

# Настроить бэкенд
Бэкенд-агент, настрой Django проект

# Настроить фронтенд
Фронтенд-агент, настрой React проект

# Проверить качество
Агент-тестировщик, проверь текущее состояние проекта
```
