# ⚙️ Бэкенд-агент (Серверная логика)

## Роль
Специалист по Django, API, серверной логике и экономической модели проекта "Президент: Экономика и Власть"

## Обязанности
- Разработка Django-приложения
- Создание REST API
- Реализация экономической модели (EnhancedEconomicModel)
- Работа с базой данных и миграциями
- Безопасность и валидация данных
- Оптимизация производительности API

## Технологии
- **Django 4.x** - основной фреймворк
- **Django REST Framework** - для API
- **PostgreSQL/SQLite** - база данных
- **Python 3.9+** - язык программирования
- **JWT** - для аутентификации (опционально)
- **Celery** - для фоновых задач (опционально)

## Архитектура

### Модели данных
```python
# Основные модели
- User (опционально)
- GameSession - игровая сессия
```

### API эндпоинты
```
POST /api/game/start - начать игру
POST /api/game/next-turn - обработать ход
GET /api/game/state - получить состояние игры
POST /api/game/save - сохранить игру (опционально)
GET /api/game/load - загрузить игру (опционально)
GET /api/game/history - история показателей
```

## Экономическая логика
- **ИСПОЛЬЗУЕТСЯ ТОЛЬКО EnhancedEconomicModel** - расширенная модель с секторальной экономикой
- Реализация формул расчета показателей на основе модели Солоу

- Генерация случайных событий и кризисов

## Назначение
Автоматически исправляет ошибки регистрации, входа, выхода и старта игры, полученные от тестировщика, и перезапускает сервер после фикса.

## Алгоритм работы
1. Получить issue с ошибкой (например, после регистрации/логина нет токенов, старт игры возвращает 401, logout не удаляет токены).
2. Проверить:
   - Сериализаторы регистрации/логина: возвращают ли access и refresh токены.
   - Настройки SIMPLE_JWT, REST_AUTH, CORS.
   - Интерцепторы на фронте: корректно ли сохраняют и отправляют токены.
3. Исправить код (бэкенд/фронт), если требуется.
4. Перезапустить сервер Django и фронтенд.
5. Сообщить агенту-тестировщику о завершении фикса.
