# 🧪 Тестовая задача для оркестра агентов

**Описание:** Протестировать полный цикл создания новой игры в приложении "Президент: Экономика и Власть"

**Приоритет:** Высокий
**Сложность:** Средняя
**Время выполнения:** 15-20 минут

## 🔄 Последовательность выполнения

### Этап 1: Подготовка (2-3 минуты)
1. **Агент-архитектор** планирует последовательность действий
2. **Агент-DevOps** проверяет готовность инфраструктуры
3. **Агент-надзиратель** инициализирует мониторинг

### Этап 2: Бэкенд-тестирование (5-7 минут)
1. **Бэкенд-агент** проверяет API endpoints
2. **Агент-тестировщик** выполняет автоматизированные тесты
3. **Агент-аналитик** валидирует экономическую модель

### Этап 3: Фронтенд-тестирование (5-7 минут)
1. **Фронтенд-агент** проверяет пользовательский интерфейс
2. **Агент-тестировщик** тестирует интеграцию фронтенд-бэкенд
3. **Агент-архитектор** контролирует интеграцию

### Этап 4: Анализ и отчет (3-5 минут)
1. **Агент-аналитик** создает аналитический отчет
2. **Агент-надзиратель** генерирует отчет об эффективности
3. **Агент-архитектор** подводит итоги

## 🚨 Возможные проблемы и решения

### Проблема: API не отвечает
**Решение:** Агент-DevOps перезапускает сервер, Агент-архитектор координирует действия

### Проблема: Ошибки в экономической модели
**Решение:** Агент-аналитик корректирует формулы, Бэкенд-агент обновляет код

### Проблема: Проблемы с фронтендом
**Решение:** Фронтенд-агент исправляет UI, Агент-тестировщик проверяет исправления

### Проблема: Низкая производительность
**Решение:** Агент-надзиратель применяет автоматические корректировки
