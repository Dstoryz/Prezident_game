## 🎯 Приоритеты проверок

### Критично (выполнять в первую очередь):
1. **Аутентификация** - регистрация, вход, выход
2. **Создание игры** - новая игровая сессия
3. **Следующий ход** - экономическая модель работает
4. **Frontend-Backend связь** - API запросы работают
5. **База данных** - миграции применены

### Важно (выполнять во вторую очередь):
1. **Экономические показатели** - все параметры влияют на модель
2. **События** - генерируются и отображаются
3. **Демография** - население изменяется реалистично
4. **UI/UX** - интерфейс удобен и понятен
5. **Производительность** - время отклика приемлемое
