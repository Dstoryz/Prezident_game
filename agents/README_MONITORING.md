# 📊 СИСТЕМА МОНИТОРИНГА И ОТЧЕТОВ

## 🎯 Обзор

Создана комплексная система мониторинга агентов и автоматических отчетов для проекта "Президент: Экономика и Власть".

## 🛠️ Доступные инструменты

### 1. 📊 Живой репортер (основной)
```bash
./agents/live_reporter.sh
```
- **Функция**: Выводит отчеты каждую минуту в текущем окне
- **Особенности**: 
  - Автоматическое обновление каждую минуту
  - Уведомления о выполненных задачах
  - Очистка экрана каждые 5 минут
  - Показ последних событий агентов

### 2. 🔔 Система уведомлений о задачах
```bash
./agents/task_notifier.sh
```
- **Функция**: Отслеживает изменения в TODO листе
- **Особенности**:
  - Проверка каждые 30 секунд
  - Уведомления о новых выполненных задачах
  - Детальная статистика прогресса

### 3. 📈 Улучшенный мониторинг
```bash
./agents/enhanced_monitor.sh
```
- **Функция**: Подробный мониторинг с полными отчетами
- **Особенности**:
  - Полная информация о статусе агентов
  - Детальная информация о портах
  - Активные процессы разработки
  - Последние события всех агентов

### 4. ⚡ Быстрый статус
```bash
./agents/quick_status.sh
```
- **Функция**: Быстрый просмотр текущего состояния
- **Особенности**:
  - Мгновенный отчет
  - Компактная информация
  - Подходит для быстрых проверок

## 📋 Что отслеживается

### 🤖 Агенты
- **architect**: Архитектор проекта
- **backend**: Backend разработка (Django)
- **frontend**: Frontend разработка (React)
- **testing**: Тестирование
- **devops**: DevOps и инфраструктура
- **analyst**: Аналитика и отчеты

### 🌐 Порты
- **8000**: Django API сервер
- **3000**: React Development Server

### 📈 Прогресс
- **TODO лист**: Количество выполненных/общих задач
- **Процент выполнения**: Автоматический расчет
- **Новые задачи**: Уведомления о выполненных задачах

### ⚡ Процессы
- **Django процессы**: `manage.py runserver`
- **React процессы**: `react-scripts`
- **Тестовые процессы**: `manage.py test`

## 🎮 Управление

### Запуск всех систем
```bash
# Живой репортер (основной)
./agents/live_reporter.sh

# Система уведомлений (в отдельном терминале)
./agents/task_notifier.sh

# Улучшенный мониторинг (в отдельном терминале)
./agents/enhanced_monitor.sh
```

### Быстрые команды
```bash
# Быстрый статус
./agents/quick_status.sh

# Проверка агентов
ps aux | grep -E "(architect|backend|frontend|testing|devops|analyst)"

# Проверка портов
lsof -i :8000 && lsof -i :3000

# Просмотр логов
tail -f agents/logs/*.log
```

### Остановка
```bash
# Остановка всех агентов
pkill -f "agent.*sh"

# Остановка мониторинга
Ctrl+C (в окне с репортером)
```

## 🔧 Настройка

### Интервалы обновления
- **Живой репортер**: 60 секунд
- **Уведомления о задачах**: 30 секунд
- **Улучшенный мониторинг**: 60 секунд

### Цветовая схема
- 🟢 **Зеленый**: Успешно, работает
- 🟡 **Желтый**: Предупреждение
- 🔴 **Красный**: Ошибка, не работает
- 🔵 **Синий**: Информация
- 🟣 **Фиолетовый**: События

## 🚀 Рекомендации

1. **Основной мониторинг**: Используйте `live_reporter.sh` для постоянного отслеживания
2. **Уведомления**: Запустите `task_notifier.sh` в отдельном терминале для уведомлений о задачах
3. **Детальный анализ**: Используйте `enhanced_monitor.sh` для глубокого анализа
4. **Быстрые проверки**: Используйте `quick_status.sh` для мгновенных проверок

## 🔄 Автоматизация

Все агенты автоматически:
- Читают TODO лист
- Выполняют задачи по своей специализации
- Отмечают выполненные задачи
- Делают повторные попытки при ошибках
- Запускают необходимые сервисы

Система мониторинга автоматически:
- Отслеживает изменения в TODO листе
- Выводит отчеты по расписанию
- Уведомляет о новых выполненных задачах
- Показывает статус всех компонентов
